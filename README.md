## 特色功能

#### 易用的魔晶石镶嵌

镶嵌一件5孔装备仅需6次点击，所选魔晶石直接展示在主界面上，查看时无需额外操作。

#### 直观的装备信息展示

加粗显示装备的第一副属性，可以一眼看出这是一件主什么属性、属性上限多少的装备。

用不同颜色显示竞品装备，在一些典型场景（比如点数零式装备混搭）下更易于识别装备。

国服还未实装的装备显示为获取途径，并标明实装版本。

#### 属性阈值和伤害期望

虽然实战中有更多影响因素需要考虑，但利用这些参数，可以很好地处理难以宏观分析的【信念/直击选择】和部分【装等/副属性选择】问题。

#### 信念/直击分配优化

随着游戏的调整与改进，信念属性和直击属性的收益越来越平衡了，这也意味着选择信念还是直击越来越难以直观决定，根据联合增伤期望精确计算可以得到更为可靠的分配方案。

#### 魔晶石用量预估

按照期望数量准备石头，意味着实际镶嵌时够用的可能性也就刚刚一半多点，临时买石头可不太妙，所以还给出了90%/99%把握完成镶嵌所需的数量。

#### 品级同步

配合属性阈值和伤害期望，可以更好地为绝境战、幻巧战等场景配装。

#### 导入

支持从一些其他配装器导入配装。

## 无速度自动配装

选择战斗职业和明确的品级同步值后，可以通过顶部的“自动配装”打开求解器。

求解器使用以下规则：

* 过滤所有提供技速或咏速的装备、食物和魔晶石。
* 非同步装备只考虑与同步品级相同、或比同步品级低 5 的装备。
* 高品级同步装备必须在同步后至少有两项满值副属性（暴击、信念、直击或坚韧）。
* 非同步装备的每个孔使用可合法镶嵌的最高值魔晶石。暴击溢出不超过 10% 时固定优先暴击，其余孔在有效伤害属性中优化。
* 两枚戒指必须使用不同的装备 ID。
* 食物固定为当前选择；没有选择食物时按无食物计算。

计算前可以锁定任意当前装备。锁定只固定装备 ID，装备上的魔晶石仍会按上述规则重新分配。未锁定的武器和其他部位均参与搜索；当前已配置属性的自定义装备会作为候选保留。

搜索按部位累计属性，并合并累计属性完全相同的状态。例如衣服提供 `5+10`、裤子提供 `10+5`，与两者属性对调后的组合只计算一次。计算在 Web Worker 中执行，不会阻塞页面；完成后可以预览结果并一键应用。

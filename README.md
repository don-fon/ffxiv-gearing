# 最终幻想14配装器

https://asvel.github.io/ffxiv-gearing/

原备用域名因平台方运营调整无法再更新，如无法使用主域名可以考虑使用[第三方镜像](https://ffxivgearing.neko7ina.com/)，此镜像由第三方维护会存在一定程度的更新延迟。

## 特色功能

#### 易用的魔晶石镶嵌

镶嵌一件5孔装备仅需6次点击，所选魔晶石直接展示在主界面上，查看时无需额外操作。

#### 直观的装备信息展示

加粗显示装备的第一副属性，可以一眼看出这是一件主什么属性、属性上限多少的装备。

用不同颜色显示竞品装备，在一些典型场景（比如点数零式装备混搭）下更易于识别装备。

国服还未实装的装备显示为获取途径，并标明实装版本。

#### 属性阈值和伤害期望

虽然实战中有更多影响因素需要考虑，但利用这些参数，可以很好地处理难以宏观分析的【信念/直击选择】和部分【装等/副属性选择】问题。

#### 信念/直击分配优化

随着游戏的调整与改进，信念属性和直击属性的收益越来越平衡了，这也意味着选择信念还是直击越来越难以直观决定，根据联合增伤期望精确计算可以得到更为可靠的分配方案。

#### 魔晶石用量预估

按照期望数量准备石头，意味着实际镶嵌时够用的可能性也就刚刚一半多点，临时买石头可不太妙，所以还给出了90%/99%把握完成镶嵌所需的数量。

#### 品级同步

配合属性阈值和伤害期望，可以更好地为绝境战、幻巧战等场景配装。

#### 导入

支持从一些其他配装器导入配装。

## 指定速度自动配装

选择战斗职业和明确的品级同步值后，可以通过顶部的“自动配装”打开求解器。

求解器使用以下规则：

* 先输入目标 GCD（例如 `2.50` 秒）；装备、魔晶石和当前食物全部生效后，使用当前职业的技速或咏速及职业 GCD 修正按游戏内取整规则计算，仅保留最终 GCD 精确等于目标值的方案。同一 GCD 档位内的不同速度属性值均可参与优化。
* 非同步装备只考虑与同步品级相同、或比同步品级低 5 的装备；治疗职业会先检查这些高品级候选能否为普通部位提供至少一件、为戒指提供两枚可合法装备的无信仰装备，数量不足时才从当前品级筛选范围内按品级从高到低加入无信仰候选，满足数量后停止放宽。
* 高品级同步装备必须在同步后至少有两项满值副属性（暴击、信念、直击、坚韧或当前职业的技速/咏速）。
* 非同步装备的每个孔使用可合法镶嵌的最高值魔晶石，精确枚举暴击、信念、直击、坚韧和当前职业的速度属性，不固定优先暴击。
* 标记为唯一品的戒指不能重复装备；非唯一品戒指允许两枚使用相同的装备 ID，并分别优化魔晶石。
* 坦克职业可以要求最终坚韧减伤不低于指定百分比，再在满足条件的方案中搜索最高伤害；输入 `0` 即为无减伤限制的最高伤害搜索。
* 食物固定为当前选择；没有选择食物时按无食物计算。

计算前可以锁定任意当前装备。锁定只固定装备 ID，装备上的魔晶石仍会按上述规则重新分配。未锁定的武器和其他部位均参与搜索；当前已配置属性的自定义装备会作为候选保留。

搜索会先合并同一部位上的等价候选：同步装只比较同步后的有效属性，不比较不再生效的原始属性上限和孔位；非同步装则比较属性、上限和魔晶石孔。唯一品与非唯一品分别判定等价；戒指每类等价候选最多保留两枚，以便唯一品仍可组成合法配对。同一速度贡献下，若一个候选的所有伤害属性都不低于另一个，则提前删除后者。进入整套搜索前，求解器会根据其他搜索组的最小、最大速度反复删除不可能达到目标 GCD 的候选，并执行只考虑速度的动态规划：枚举各组可产生的不同累计速度，再反向标记能够精确进入目标 GCD 档位的速度路径，提前删除未参与任何合法速度路径的装备和魔晶石方案。随后将具有明显压缩收益的两个部位提前组合，例如衣服提供 `5+10`、裤子提供 `10+5`，与两者属性对调后的组合会在接触其他部位前合并。组合完成后会重新建立速度路径；后续属性搜索只展开合法速度转移，按组累计属性，合并累计属性完全相同的状态，并在每一层对相同速度的累计状态执行同样的全属性支配剪枝。最终评分阶段会为累计状态和最后一组候选分别建立属性上界树；当两棵子树能够提供的各项最高属性仍无法超过当前最优伤害时，直接跳过两棵子树的整个笛卡尔积。一个 GCD 档位包含多个可达精确速度时，页面会先列出这些速度，再使用最多四个 Web Worker 分别求解并取全局最高伤害；各分区互不重叠且覆盖全部可达速度，因此仍为精确最优解。上述剪枝只删除最终伤害不可能更高的状态，不依赖当前暴击等属性的边际收益。计算在 Web Worker 中执行，不会阻塞页面；完成后可以预览结果并一键应用。

多速度搜索会先对所有可达速度执行快速贪心预搜索，取得一个合法的全局伤害下界，并优先计算最有希望及预计工作量较大的速度分区。后续精确搜索只用该结果排除理论上界不可能超过它的分支，因此不会把启发式结果当作最终最优解，也不会降低精确性。

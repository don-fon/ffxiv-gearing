# 坦克统一整段GCD搜索（2026-10-28）

删除 `canSearchSpeedInterval` 中的 `mainStat !== 'VIT'`。坦克与其他普通职业使用同一整段GCD入口，
保留后端能力、工作量、组数和食物条件等既有适用性判断。未启用实验梯度，也未部署。

## 为什么此前分流

职业排除来自提交 `2a55d3c`。当时围绕武僧实现和验证区间搜索，流程测试也没有包含坦克种子。
没有找到证明坦克必须分流的数学要求或完整对照依据。把尚未验证的范围长期写成职业限制是不合理的。
最低减伤和折算目标确实需要不同数学约束，但应在公共求解器内正确表达，而不是按职业排除整个搜索路径。

## 统一流程时补齐的上界

只删除排除条件能大幅减少分片，但会放大坚韧上界过松的问题，故不能只交付这一行修改：

- 最低减伤：反解连续食物上包络，得到安全的原始TEN下界；副属性预算不能再把TEN减少到该下界以下。
  游戏取整和浮点容差向保守方向处理，仍逐叶检查真实减伤。
- 减伤折算：在原始TEN不低于基准的有效域内，将额外评分乘数的对数切线加入同一个TEN维度，
  与其他伤害因子共同计算相关上界。条件不满足时保留原乐观上界。
  实际伤害和用户评分公式不变，WASM ABI仍为7。

## 完整运行结果

真实 Chromium、4 Workers、冷启动、未提供已知答案。旧路径部分数据复用此前同输入完整运行，
高/低暴击旧路径在本轮重新测量。每种新配置每个阶段一次，秒级波动不解释为稳定收益。

| 配置 | 旧路径秒 | 仅统一入口秒 | 统一入口并补齐上界秒 |
|---|---:|---:|---:|
| 战士375/GCD2.48 | 81.14 | 8.97 | 8.38 |
| 骑士605/GCD2.45 | >180，未完成 | 72.95 | 72.62 |
| 战士375默认 | 6.78 | 3.94 | 3.42 |
| 战士375最低减伤10% | 8.98 | 162.33 | 15.07 |
| 战士375折算比例0.5% | 7.67 | 27.55 | 2.92 |
| 战士375折算比例10% | 23.82 | >180，未完成 | 2.67 |
| 战士375高暴击 | 7.69 | 3.67 | 3.64 |
| 战士375低暴击 | 14.49 | 3.54 | 3.32 |

战士GCD2.48分片184→6，骑士GCD2.45分片1136→6。
完整对照的最优目标值一致；骑士旧路径没有完成，不声称有独立旧路径最优值证明。
每个完成结果从候选装备、镶嵌上限和食物重新累加属性，验证GCD、唯一装备、槽位、暴击及坚韧条件。

最低减伤10%仍比旧路径约慢6秒，这是剩余的性能回退，不能声称每个配置都变快。
新路径已经统一，后续应继续改善公共约束上界，而不是重新增加坦克身份排除。

# 暴击模式覆盖与性能验收

## 修复

`1d96454` 去掉 `improveSpeedIntervalSeed` 对高/低暴击的限定。不限暴击也使用相同的有界两部位替换，提高合法初始下界与精确搜索参考质量。启用条件只保留后端能力和工作量门槛。

`betterSpeedIntervalSeed` 的偏好判断保留：不限暴击的初始解本来就来自同一个贪心算法，再执行一次没有价值。旧版 `improveGreedySolution` 仅支持各部位速度固定的预搜索，不能替代整段 GCD 的新预搜索。

测试明确检查 none/high/low 都执行区间预搜索，并逐一与 JS 求解结果及暴击范围比较。最终结果仍须完成精确搜索。

## 验收规则

- 同一真实输入分别执行不限、高暴击、低暴击，保存每种模式的完成情况、完整耗时、目标值和约束。
- 性能基准串行运行；包含候选规划、Worker 初始化、搜索及返回结果。
- 区分冷启动与预先注入合法下界，禁止混为同一配对对照。
- 至少检查战士和画家真实输入结果回归，另跑算法与生产浏览器测试。
- 超时与主动停止只提供耗时下界，不代表完整最优解。进度与分支数不能代替完整耗时。
- 50% 收益门槛按明确的场景判定；一个场景通过不得宣称所有模式都通过。
- 通用改动优先统一启用条件；模式或职业特例需解释正确性或性能依据。

## 复现

生产构建后，在同一机器串行运行：

```sh
for mode in none high low; do
  node scripts/benchmark-optimizer.mjs --skip-build --chromium /usr/bin/chromium --engine auto --workers 4 --critical "$mode" --timeout 900000 --input test/fixtures/monk-605-phantom-input.json --output "/tmp/mnk605-$mode.json"
done
```

场景：武僧 90、同步 605、装备 350–795、幻武暴击/信念满值及直击 108、GCD 1.94。不开额外锁定，4 Worker，自动选择食物。

## 实测结果

| 场景 | 完整秒数 | 伤害 |
| --- | ---: | ---: |
| mnk605-all-modes-none | 157.726 | 27.30352779435699 |
| mnk605-all-modes-high | 156.449 | 27.280971280704218 |
| mnk605-all-modes-low | 785.515 | 27.30352779435699 |
| all-modes-war | 6.968 | 7.966430616454143 |
| all-modes-pct | 2.351 | 12.8560955257727 |

三种模式均完成 4/4，冷启动，未注入已知最优下界。不限暴击旧版运行 917.170 秒仍只有 2/4，当前 157.726 秒完整完成，耗时保守降低超过 82.8%。旧版未完成，不能给出精确加速倍数。高暴击结果与旧完整基线一致；低暴击与不限暴击结果相同，但耗时仍明显较长，不能宣称所有模式都达到实用性能。

低暴击执行逻辑本次未改变；这里只建立完整基线，不声称其取得提速。战士、画家结果与既有基线一致。76 项算法测试、13 项生产浏览器测试、lint、生产构建通过；产物逻辑对应本提交，构建后的源码仅追加解释性注释。

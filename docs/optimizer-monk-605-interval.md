# 武僧 605：直接搜索整个 GCD 区间

场景：350–795、同步 605、幻武暴击/信念拉满且直击 108、GCD 1.94、高暴击，4 Worker，Chromium 154。输入为 `test/fixtures/monk-605-phantom-input.json`。

## 改动

- 修复 WASM 每次查询重新分配根指针数组造成的线性内存增长；10 万次查询的回归测试验证内存保持稳定。
- ABI 6 将速度范围纳入原生树节点。直接搜索整个合法 GCD 区间，避免 JS 为每一种精确速度组合反复调用后端。叶节点仍逐一检查游戏取整后的 GCD。
- 上界同时考虑速度所消耗的副属性预算和暴击区间，提前排除不可能改善当前结果的子树。
- 高/低暴击先比较合法贪心方案与暴击端点方案，再进行有次数上限的两部位替换，改善初始下界和证明使用的参考属性。每次替换重新检查伤害、暴击及 GCD；最终仍须完成精确搜索。
- 大型普通职业任务启用区间路径；坦克、青魔和小型任务继续使用既有路径。日志显示“WASM GCD 区间搜索”。

## 对照与采用依据

既有完整基线耗时 2775.072 秒，1344/1344 分片完成，且预先给定合法最优方案作为下界。新版以同一下界完成全部 4 个食物任务，耗时 234.081 秒，降低 91.6%，超过组合优化的 50% 门槛。

单项价值：仅启用区间搜索、仍使用暴击端点参考的版本，600 秒只完成 2/4；改善合法贪心参考后 234.081 秒完成。冷启动不做两部位替换的版本，694.098 秒仍只有 3/4；加入替换后 169.328 秒完成 4/4。超时或主动停止的记录仅作耗时下界，不视作完整结果。

新版冷启动没有注入已知答案，返回伤害 27.280971280704218，与既有完整证明一致。属性为 STR 2586、CRT 2091、DET 1697、DHT 1447、SKS 766；食物为焦糖爆米花。候选集合、镶嵌规则、暴击中点和目标函数均未改变。

这些是同一云端机器的单轮测量，不代表所有职业和本地机器都有相同比例。旧版带已知下界、新版冷启动的耗时不能直接当作严格配对速度比。

## 复现

```sh
npm run build
node scripts/benchmark-optimizer.mjs --skip-build --chromium /usr/bin/chromium --engine auto --workers 4 --critical high --timeout 900000 --input test/fixtures/monk-605-phantom-input.json --output /tmp/mnk605-interval.json
```

新增独立穷举覆盖 300 组速度、食物、暴击偏好和浮点属性组合；另有速度树分裂、缓存区间变更、公开规划/求解入口与 JS 结果一致性测试。

## 最终保留版本

最终源码 `1d99295` 冷启动完成 4/4，耗时 **162.938 秒（2 分 43 秒）**，结果与上述最优值一致。尝试按参考暴击附近优先搜索的版本耗时 169.328 秒，没有显示增量收益，已移除该搜索顺序改动。

完整配对基准的 91.6% 降幅满足采用门槛；最终冷启动耗时用于说明实际使用体验。各实验的精简原始结果保存在 `docs/benchmarks/monk-605-interval-*.json`。

验证通过：76 项优化器测试、13 项生产浏览器测试、lint、生产构建和 WASM 源码/产物一致性检查。战士 375 与画家 375 完整回归伤害分别保持 7.966430616454143、12.8560955257727。

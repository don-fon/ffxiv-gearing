# 自动配装性能与逐项验证（2026-10-25）

候选范围后续已修正为“当前列表显示的装备（范围内加手动选定）”；本文 956 件候选的计时属于旧输入，不代表新范围的耗时。见 [候选范围修正](optimizer-candidate-scope.md)。

采用门槛：同一输入、相同 Worker 数，完整求解耗时至少降低 50%；允许多项优化组合。保留精确最优解、目标 GCD、坚韧约束、合法镶嵌和戒指规则。

## 原始场景的浏览器实测

战士 70 级，筛选 350–375、同步 375、GCD 2.50、坚韧要求 0%、无锁定/排除、全部候选食物，956 件输入候选，4 Worker。Chromium 154.0.8037.57，Node 24.19.0，同一云容器（CPU 配额 4 核），串行运行各组测试。

计时从创建规划 Worker 开始，包括规划、Worker 启动、WASM 下载/实例化、消息传输和全部分片搜索。使用生产构建和真实浏览器 Worker，不以 C 内核微基准代替页面完整计算。

| 配置 | 完成任务 | 总耗时 | 结果 |
| --- | --- | --- | --- |
| 原纯 JS | 1/4 | 400.0005 秒后中止 | 尚未完成，不能给出最终耗时 |
| WASM 去重 + WASM 搜索 + 两组预搜索 + 候选分片 | 16/16 | 158.6281 秒 | 精确完成 |
| 最终默认配置复跑（自动选择 WASM） | 16/16 | 174.3901 秒 | 精确完成 |

两次完整计算耗时 158.6–174.4 秒。采用较慢一次，保守耗时降低至少 **56.40%**：`1 - 174.3901 / 400.0005`。JS 的 400 秒是超时下限，不能称为“原版完成耗时”。不能据此保证所有职业/筛选条件都有相同比例提升。

伤害期望 `8.080836870815013`，GCD `2.50`，STR 1282、CRT 1382、DET 1270、DHT 556、SKS 364、TEN 454、VIT 1457，食物 49240。与此前完成的独立搜索结果一致；所选装备和魔晶石可从 fixture 重建全部属性。

原始记录：[JS 超时](benchmarks/browser-primary-js.json)、[优化完成](benchmarks/browser-primary-optimized.json)、[最终默认配置复跑](benchmarks/browser-final-default.json)。

## 各项优化的消融

同一实际输入，锁定最终方案的武器、手套、鞋及其魔晶石，固定食物 49240、速度贡献 0，单 Node 进程。每次新进程，包含 WASM 初始化；不含浏览器规划与 Worker 传输。此组用于解释组件收益，不能混充上表的浏览器端到端结果。

| 配置 | 重复次数 | 耗时中位数 | 相对纯 JS 降低 |
| --- | --- | --- | --- |
| 原 JS | 3 | 18.470 秒 | — |
| 仅 WASM 最终树搜索 | 2 | 15.465 秒 | 16.3% |
| 仅 WASM Pareto 去重 | 2 | 8.090 秒 | 56.2% |
| WASM 去重 + 最终搜索 | 3 | 5.852 秒 | 68.3% |

仓库附带的组件复现脚本另一次串行验证得到 JS 18.678 秒、组合 5.778 秒，降低约 69.1%；[复现记录](benchmarks/component-reproduction.json)。

最终搜索在“已有 WASM 去重”的基础上进一步降低约 27.7% 耗时，因此两者都有增量价值。去重仍保留所有不被支配的属性点，未改成近似筛选。原始记录：[消融数据](benchmarks/ablation.json)。

额外尝试：单组局部搜索没有提高初始下界，未采用；跳过含单候选组的合并，JS 单次 18.215 秒、组合单次 5.583 秒，接近波动范围且不影响原始无锁定场景，未采用。

原始场景、4 Worker 的额外消融（均精确完成，伤害和全部属性一致）：

| 关闭项目 | 总耗时 | 相比最终默认配置复跑的增量收益 |
| --- | --- | --- |
| 关闭两组预搜索，保留 WASM 与分片 | 212.955 秒 | 启用预搜索减少 18.1% |
| 关闭额外候选分片，保留 WASM 与预搜索 | 258.948 秒 | 启用分片减少 32.7% |

记录：[无预搜索](benchmarks/browser-no-warm.json)、[无额外分片](benchmarks/browser-no-shards.json)。这些收益不能相加，组件之间存在相互影响。

两组预搜索只改进合法初始方案，最多两轮、每次查询限制 500,000 分支，绝不把中断的预搜索当作最优证明。只用于估计搜索空间至少 100 亿且各组只有一种可行速度的大任务。候选分片在依赖下界的剪枝之前，按固定组的属性签名分割；各 Worker 的下界可以不同，合并仍覆盖完整候选空间。小任务保持原有划分。

## 正确性、兼容性与复现

验证结果：65 项优化器测试、6 项生产构建浏览器测试通过，lint 与生产构建通过；C 源码重建的 19,445 字节 WASM 与仓库产物逐字节一致。各优化的独立提交快照也分别通过其优化器测试、lint 和生产构建。

WASM 与 JS 对照覆盖物理/法系/治疗/青魔，70/100 级、队伍加成、取整、比例/固定食物、镶嵌溢出、装备锁定、唯一戒指、GCD 与坚韧约束。独立重建返回装备的全部属性；随机去重集合对照保留相同非支配坐标；分片与不同合法初始下界、JS/WASM 混合执行对照未分片最优值。原有优化器还包含小规模枚举 oracle。

正常页面优先使用 WASM，初始化失败（网络、浏览器不支持）自动回退 JS；显式性能测试指定 WASM 时失败会明确报错，防止把回退结果误标为原生性能。运行中的内核错误也会明确报错。本轮实际浏览器测试使用 Chromium。仍用 Web Worker 隔离计算，WASM 替换的是计算热点，不是浏览器线程机制；无需服务器、SharedArrayBuffer 或跨域隔离头，兼容 GitHub Pages。

```sh
npm run test:optimizer
npm run lint
npm run build
npm run benchmark:optimizer -- --engine javascript --workers 4 --timeout 400000 --output /tmp/js.json
npm run benchmark:optimizer -- --engine auto --workers 4 --output /tmp/native.json
```

若使用系统 Chromium，追加 `--chromium /usr/bin/chromium`。每次基准默认构建生产资源，`--skip-build` 可复用固定构建。组件消融可分别运行 `npm run benchmark:optimizer-components -- --engine javascript`、`--engine wasm-final`、`--engine wasm-pareto`、`--engine wasm`；每次调用新进程，默认 JS 基线固定在 `a83d506`，可用 `--baseline current` 比较修正后的 JS。

浏览器消融可用 `--engine wasm` 禁用两组预搜索，`--shards 1` 禁用额外候选分片；`--locks 3 --food 49240` 用于中等真实场景。超时输出保留已完成任务数和当前最佳评分，不会伪造完整结果。

仓库包含 C 源码及约 19 KB WASM 产物，普通安装/构建无需 C 编译器。修改 C 后使用 LLVM 19 的 clang/lld：

```sh
WASM_CC=clang-19 WASM_LD=/usr/bin/wasm-ld-19 npm run build:optimizer-wasm
WASM_CC=clang-19 WASM_LD=/usr/bin/wasm-ld-19 npm run build:optimizer-wasm -- --check
```

构建禁止 fast-math 与浮点融合，保留游戏公式的运算顺序。`--check` 校验已提交二进制与源码重建结果完全相同。浏览器和设备不同会影响绝对耗时；原始 JS 对照超时的场景只报告保守降低比例。

预览地址：<https://don-fon.github.io/ffxiv-gearing/preview/>。产物发布提交 `a09f7d5`，源码运行配置来自 `d97980b`。仅更新 `preview/`，发布页根目录逐文件与原发布版本 `8903328` 一致。

线上 HTML、Worker、主脚本和 WASM 通过启用证书校验的 HTTPS 下载，SHA-256 与发布产物逐项一致：[资源校验记录](benchmarks/pages-assets.json)。云容器 Chromium 直连 GitHub Pages 时出现 `ERR_CERT_AUTHORITY_INVALID`，因此未声称线上浏览器测试通过，也未跳过证书检查。上述 6 项真实浏览器测试针对同一生产产物在本地 HTTP 服务运行，包含 WASM 成功加载及阻断下载后的 JS 回退。

后续的暴击偏好功能已将内核更新至 ABI 3、19,778 字节；本文的性能数据与 19,445 字节产物校验属于原测试版本。新增规则与验证见 [暴击偏好](optimizer-critical-preference.md)。

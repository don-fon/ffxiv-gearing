# 统一路径后的全局梯度复测（2026-10-28）

结论：当前梯度原型仍不适合无条件全局启用。
本轮基线是 `6026968` 的统一坦克GCD路径及坚韧预算/折算相关上界，不复用旧坦克路径的梯度结论。
梯度细化移植到新C内核，保留新的坚韧下界和评分切线，以仅上界模式运行，没有改变用户目标或候选。

## 完整对照

4 Workers、真实Chromium、冷启动、不给已知最优值，8个真实配置全部完成，目标值一致。
基线复用同输入的统一版本完整运行；最低减伤案例额外做了同一时段的基线→梯度配对复测。
每单元首次测一次，秒级差异不解释为稳定收益。

最低减伤案例再次配对复测：普通版本15.42秒、梯度版本52.07秒。
首次对照的分支数为44,390,830→156,336,626，累计WASM时间13.29→50.78秒。
本轮没有在梯度函数入口/出口单独计时，不能把该案例的退步继续归为旧战士案例的梯度计算成本。
新的切线和搜索顺序下分支明显增多，说明统一路径解决重复查询，并不保证细化后的搜索整体更有效。
也不能把骑士约22秒的收益直接推广到其他任务。

## 正确性与适用范围

- 移植后的原生内核12项测试通过，包含900组独立穷举及坦克整条区间流程，覆盖最低减伤、折算、食物封顶和高低暴击。
- 8个真实配置的装备/镶嵌/食物重新累加后属性一致，GCD、唯一装备和槽位验证通过；目标值与普通版本一致。
- 这是8个坦克配置的反例检验，不是所有职业全量性能普查。明确的可重复回退已足以否定当前原型“无条件全开”。
- 旧版本的按需门槛也需在新内核上重新验证，不能直接当作已经选定的默认策略。

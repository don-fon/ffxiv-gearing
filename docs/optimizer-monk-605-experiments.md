# 武僧同步 605：未采用的性能试验

条件：装备范围 350–795、武僧 90 级、同步 605、GCD 1.94、固定幻境旋棍·秘影（同步后 CRT 269、DET 269、DHT 108）、全部候选食物、高暴击。完整范围的 CRT 端点为 669–2472，中点 1570.5；4 Worker，Chromium 154.0.8037.57，完整生产 Worker 流程。

| 版本 | 时间上限 | 完成分片 | 结果 |
| --- | --- | --- | --- |
| 当前发布版本 | 180 秒 | 0/1344 | 超时 |
| 向无坚韧普通职业扩展关联上界 | 180 秒 | 0/1344 | 超时 |
| 扩展上界＋武僧跳过中间状态展开 | 180 秒 | 0/1344 | 超时 |
| 原搜索＋选择伤害更高的合法暴击初始方案 | 180 秒 | 0/1344 | 超时 |

以上时间均为停止上限，不是完成耗时。不能据此计算精确加速比，也不能证明这些方案在所有输入上无收益；本例没有验证出至少 50% 的完整求解耗时降低，因此全部撤回，未更改发布版本。

扩展上界需要取消非坦克的坚韧乘数，并保守排除 BLU、含坚韧装备/食物/镶嵌等未覆盖条件。原有 71 项优化器测试通过，另将原生上界穷举对照扩充 180 组非坦克输入后通过。正确性回归通过不等于性能合格。直接搜索组合也未产生完成结果，故没有保留职业特例。

第三组仅调整高暴击初始方案：将合法贪心方案与原端点方案比较，选择伤害更高者。初始评分从 27.08883707103459 提高到 27.18823694513696，但完整搜索仍超时，因此也没有采用。此前辅助搜索得到的合法方案评分 27.280971280704218 仍高于这些初始解，不能将试验的初始解当作新最优解。

汇总见 [原始计时摘要](benchmarks/monk-605-experiment-summary.json)。完整运行记录及实验源码保存在云工作区 `/workspace/.cloud-setup/mnk-optimization-trials/` 与 `/workspace/.cloud-setup/mnk605-*.json`，未混入生产代码。

后续需要重新设计精确技速分片之间的共享计算，或构造更强的、包含技速代价的可达伤害上界。仅增加 Worker、修改初始方案或移植坦克上界，目前不足以证明这组输入已达到可用性能。

## 第二轮试验

在相同 180 秒限制内进一步测试：

| 方案 | 完成分片 | 结果 |
| --- | --- | --- |
| 将四属性预算界安全扩展为普通职业的三属性预算界 | 4/1344 | 超时 |
| 三属性预算界＋按食物合并技速分片 | 0/4 | 超时 |
| 三属性预算界＋在展开前排除不可能改进的候选 | 4/1344 | 超时 |
| 上述方案＋关联上界 | 0/1344 | 超时 |
| 上述组合＋武僧直接进入剩余树搜索 | 0/1344 | 超时 |

三属性预算界使用中性的坚韧乘数 1，将虚拟基准坚韧同时加到预算、上下界和参考向量，避免把不存在的坚韧当作伤害减益；真实属性和最终伤害不变。它在同一输入上约 54 秒出现完整搜索完成进度、约 68 秒已有 3 个 Worker 分片完成，显示了局部收益，但整轮仍不能完成，不能将这解释成完整求解提速至少 50%。

提前排除候选的方案还需要正确处理全局下界已经超过本分片全部可行方案的情况：保留原合法初始方案作为返回值，不能将证明无改进的分片报告成输入不可行。修正该边界后 71 项测试通过。预算界与关联上界组合还通过了扩充至 360 组的原生穷举对照（含新增 180 组非坦克输入）。

这些试验都未达到完整求解验收门槛，已全部撤回；源代码、原生内核和测试恢复发布版本。第二轮实验源码另外保存在云工作区 `mnk-optimization-trials/round2/`。正式页面和预览页未部署任何上述试验。

后续改用固定任务及固定合法下界，已验证预算界具有局部收益，见 [固定任务对照](optimizer-monk-605-budget.md)。上文撤回结论描述的是当时的决策，不代表预算界已被证明无效。

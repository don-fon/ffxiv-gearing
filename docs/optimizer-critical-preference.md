# 暴击偏好：按可行范围二分一次（2026-10-26）

候选来源后续改为直接复用当前列表显示范围，详见 [候选范围修正](optimizer-candidate-scope.md)。下文实际数据保留原测试输入，便于历史对照。

用户选择“无所谓 / 高暴击 / 低暴击”。默认无所谓，沿用原有伤害目标。

高、低暴击模式首先在当前自动配装候选中，求满足最终 GCD、最低坚韧、锁定、排除、合法镶嵌和戒指唯一限制的总暴击最小值 L、最大值 H。总暴击包括基础属性、装备、实际镶嵌和食物。所有候选食物、速度分片共用一个范围。

只取一次中点 M = (L + H) / 2：

- 高暴击：最终总暴击 ≥ M，在该半区内最大化原有伤害期望。
- 低暴击：最终总暴击 ≤ M，在该半区内最大化原有伤害期望。
- M 为半整数时，高档实际下限为向上取整，低档实际上限为向下取整；整数中点两档都包含。
- L = H 时，两档都保持可行。

不额外设置允许损失比例，也不把“高暴击”解释成只追求最大暴击。结果面板展示范围、中点和本次实际门槛。这是用户偏好约束，不是完整的武僧循环模拟。

## 实现与正确性

端点用动态规划求解，仅跟踪累计速度、满足坚韧所需的状态及暴击最小/最大值，保存合法装备路径作为搜索初始方案。无需为了端点运行两次完整伤害优化；达到坚韧要求后可合并超出的坚韧状态。

偏好模式下，属性支配筛选仅在暴击数值相同的候选之间进行，避免低暴击方案被更高暴击候选提前删除。也保留可能用于降低暴击、同时仍落在目标 GCD 档位的速度镶嵌。JS、WASM 均检查叶节点的暴击约束；树节点用暴击上下界提前排除不可能满足偏好的分支。各 Worker 继承规划阶段的统一范围，不能按自己的食物或候选分片重新二分。

无所谓模式跳过端点 DP 与上述暴击保护策略。WASM 内核升级到 ABI 3，产物 19,778 字节；未指定暴击偏好时跳过暴击区间检查。

## 验证

- 69 项优化器测试通过。新增测试独立穷举 64 组小用例，比较 JS/WASM 的可行暴击范围和半区最优伤害，覆盖食物、镶嵌溢出、职业 GCD 修正、坚韧、锁定及排除；另外验证唯一/非唯一戒指、右戒锁定、相同端点和跨分片统一范围。
- 11 项生产构建浏览器测试通过：偏好在隐藏后保留、换职业重置、切换偏好清空旧结果、范围传递与结果展示，以及三档模式各自的真实 WASM 加载和 JS 回退。
- lint、生产构建、WASM 源码重建一致性检查通过。

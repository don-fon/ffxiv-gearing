# 非零最低减伤与非2.50 GCD混合约束补测（2026-10-28）

补测的是实际需要额外技速的情况：战士同步375、范围350–375、GCD2.48，以及骑士同步605、范围580–605、GCD2.45；分别设最低坚韧减伤10%与15%，暴击不限。

固定4 Workers、真实Chromium 154、冷启动完整规划与求解流水线。输入只覆盖目标GCD及减伤要求，优化前后相同；版本顺序逐案例交替，串行运行，不并发构建或其他性能测试。每项每版一次，预算5分钟。

结果表明这项优化对混合约束有部分收益，但远未解决所有混合场景：

- 战士2.48＋10%：新版88.29秒完整结束；旧版5分钟未完成，不能宣称两版都已证明最优。
  新版伤害7.927973014548788，技速407、坚韧816，实算GCD2.48、减伤10%。
- 骑士2.45＋15%：89.23秒降到42.70秒，耗时减少约52.1%；两版完整结果伤害均为21.02962278483717。
  新版技速650、坚韧1826，实算GCD2.45、减伤15%。
- 骑士2.45＋10%、战士2.48＋15%：两版都5分钟超时，不能判断最终最优值或计算有效的完整耗时加速比。

同为骑士2.45，提高到15%反而比10%更快，实际耗时不随减伤门槛单调变化。本轮没有统计整个可行解集合的大小，不能将访问分支数等同于可行配装数。
每格仅一次运行，不推算用户总体平均收益或未测输入的性能。

完整结束的结果独立重建装备、镶嵌上限及食物属性，检查候选ID、槽位、唯一装备、精确GCD和最低减伤。两版均完整结束时才比较最优伤害；只有一版完成时，不能声称“两版最优值一致”。超时只报告未完成，不把其当前最佳伤害称为最优。

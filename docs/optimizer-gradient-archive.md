# 梯度细化方案：已归档

2026-10-30，按用户决定，因总体收益有限，将梯度细化方案归档，停止作为当前优化工作和采用候选继续推进。实验未接入网页；当前求解、常规验证与基准流程继续使用原生算法，不增加按职业或案例启用梯度的分流。

## 归档范围

归档包括迭代梯度寻找切线、每个暴击区间一次细化、梯度切线继承、父数值上界继承，以及逐子树重算等相关原型。

当前原生算法已有的静态线性松弛上界、副属性预算界、动态规划和分支定界继续使用。此次归档不移除这些已有算法。

## 最终证据

| 配置 | 原生算法 | 梯度组合 | 测量口径 |
| --- | ---: | ---: | --- |
| 武僧605／1.93／不限暴击 | 62.89秒 | 30.72秒 | 三次均值，减少51.1%，单次收益有波动 |
| 武僧605／1.94／不限暴击 | 35.76秒 | 28.19秒 | 三次均值，减少21.2% |
| 武士665／2.14 | 10.33秒 | 12.01秒 | 两次均值，增加16.3% |
| 骑士605／2.45／最低减伤10% | 396.99秒 | 368.95秒 | 延长至15分钟预算，各一次，减少7.06% |
| 战士375／2.48／最低减伤15% | 180秒未完成 | 180秒未完成 | 尚无完整耗时对照 |

补齐骑士长任务后，17个完成输入的等权耗时合计改善约10.7%，不代表用户使用频率加权的整体收益。少数案例的明显收益不足以据此采用全局方案。

父数值上界继承在额外四组消融中未改变结果或分支数，未测出独立收益；逐子树反复细化也没有建立额外价值。归档依据是收益与复杂度的取舍，不是发现本轮完成结果不一致；已测结果一致也不等于代码级形式化证明。

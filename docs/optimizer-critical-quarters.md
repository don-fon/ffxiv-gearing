# 高低暴击四分之一区间验证（2026-10-27）

用户允许为性能修改高、低暴击约束。最终只改变默认偏好边界：低暴击取可行属性数值范围的最低四分之一，高暴击取最高四分之一；范围内仍精确求最高期望伤害。不按装备数量取分位数，无所谓模式的约束不变。

此前尝试仅改变原生上界的三种版本（暴击约束乘子、加入技速乘子、按暴击档位调整参考属性）均未采用，C/WASM 已恢复。这些实验提前停止，不能当作完整性能对照或声称已证明没有收益。最终采用版本没有混入这些实验。

## 完整场景

武僧90、350–795、同步605、固定幻武暴击/信念满值及直击108、GCD1.94、4 Worker，Chromium，自动食物。所有任务串行执行，冷启动未注入答案，计时包含规划与完整搜索。输入仍为 `test/fixtures/monk-605-phantom-input.json`。

| 模式 | 原中点定义 | 四分之一定义 | 耗时降低 |
| --- | ---: | ---: | ---: |
| 低暴击 | 785.515秒 | 32.884秒 | 95.8% |
| 高暴击 | 156.449秒 | 39.662秒 | 74.6% |
| 无所谓 | 157.726秒 | 145.785秒 | 仅作回归，不声称提速 |

每轮均完成全部4个食物任务。可行暴击范围669–2472，新低暴击阈值1119.75（整数≤1119），新高暴击阈值2021.25（整数≥2022）。低暴击/无所谓最优值27.30352779435699、CRT669；高暴击最优值27.280971280704218、CRT2091。各模式最优值与各自旧完整结果一致。

新旧可行集合不同，这不是同一数学问题的纯算法加速；本案例没有改变最优值，不保证其他案例的配装或伤害不变。两种偏好模式的实测改善均超过50%采用门槛，只对上述已测场景作性能结论。低暴击运行期间未运行其他基准；无所谓回归期间补跑约1.3秒的小规模测试，不将其耗时用作精确加速对照。

## 正确性和兼容

- JS/WASM、上界和叶节点使用同一 threshold；所有食物、Worker共享规划阈值。
- 保留范围 midpoint 用于旧显式计划兼容；缺少 threshold 时沿用其旧中点，不重新解释历史固定计划。新规划始终包含 threshold。
- 独立穷举按新范围检验最优解，涵盖高/低/无所谓、食物、GCD、镶嵌、坚韧、锁定、唯一戒指、小数属性与端点相等。
- 拒绝越界、非有限阈值；界面显示实际阈值且有跨Worker传递测试。
- 76项算法测试、13项生产浏览器测试、lint、生产构建通过。

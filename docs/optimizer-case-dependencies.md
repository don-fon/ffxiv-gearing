## 对“B出现后A可能多余”的结论

这次已在当前B组合上移除A，并对主属性优先／相关界、TEN索引／压力排序做四格对照。测试结果支持有些A仍有增量；也出现短任务移除后略快、但长任务退化的情形，不能仅凭一个案例删除。

本轮没有找到足以安全全局删除的默认组件。差距小、单次波动或双双超时，不等于已经证明无用。整数实现因错误被否决，其性能消融不能用于决定旧组件删除。不存在“新模型足够快，所以旧算法现在都多余”的证据。

后续每次改变最终组合，都重新比较B与A+B；若两项互为替代，分别移除无差异也不允许同时删光。候选、评分、偏好、Worker数、计时边界或构建改变时，相应当前结论降级，保留旧数据并重测，不混用版本。

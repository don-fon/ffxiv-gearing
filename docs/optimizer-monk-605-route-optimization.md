# 武僧 605：减少速度路径分配并提前做预算剪枝

对应提交：`eb71df7`（复用缓冲区）、`cb55bd1`（速度前缀预算剪枝）。基线已包含此前原生三属性预算界，原生 WASM 与 ABI 5 本轮均未修改。

## 实际改动

- 递归复用一个节点数组，通过 push/pop 表示当前路径；每层独占属性缓冲区，代替每条路径创建新数组、新属性对象。
- 只合并伤害上界实际需要且可能存在的属性。属性集合同时考虑装备和基础属性，防止漏掉仅来自基础属性的武器伤害等值。不同分支缺失属性时清除旧值；保持原加法顺序，避免通过浮点减法回退累积误差。后端查询是同步的。
- 将 JS 侧预算界安全扩展到无坚韧的普通职业，约束与已验证原生预算界一致，虚拟基准坚韧只用于让乘数保持 1。
- 按“剩余组索引＋当前速度贡献”记忆化计算后续可达到的最大副属性总量与最小 CRT。它们可以来自不同的合法速度路径，因此是乐观上限和保守下限，不会误删可行解。
- 在进入后续速度组合前，使用当前路径、前缀状态树和剩余速度路径的预算界。即使按最有利的属性分配也无法改进合法伤害下界时，整段后续路径不再枚举。

候选装备、GCD、暴击中点、合法镶嵌和伤害公式未变。最终完整结果仍由精确搜索建立，不增加允许损失或近似停止规则。

## 正确性与范围

72 项优化器测试、13 项生产浏览器测试、lint、生产构建通过。新增独立穷举覆盖小数主属性/副属性、属性缺失、不同速度路径、三种暴击策略以及 JS/WASM。原有全局伤害下界、速度分片、唯一戒指、锁定、食物与坚韧条件测试继续通过。

战士 350–375 回归约 6.419 秒，伤害仍为 7.966430616454143；画家 375 固定幻武回归约 2.445 秒，伤害仍为 12.8560955257727。这些用于结果回归，不将跨运行时段的绝对耗时冒充精确性能对照。
